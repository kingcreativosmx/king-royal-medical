# King Royal Medical

Demo inicial para convertir las tarjetas profesionales de King Creativos en micrositios interactivos para especialistas de la salud.

## Primera demo
- Ginecóloga Victoria Tapia
- Ginecología y Obstetricia
- Paleta morado + azul cielo
- Datos de contacto ficticios

## Roadmap
1. Base técnica del proyecto
2. Convertir los tres diseños en pantallas web reales
3. Navegación y botones interactivos
4. WhatsApp, llamadas, correo y mapas
5. Generación de PDF y QR
6. Plantillas reutilizables
7. Panel editable del profesional
8. Panel King Creativos
9. Autenticación, base de datos y estadísticas
